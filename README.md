# Pixel Loom · 像素动画脚本工作台

无需后端的像素动画脚本工作台：打开 `index.html` 即可使用（或任意静态服务器托管）。所有数据保存在浏览器 `localStorage`，可导出 / 导入 JSON 项目文件。

## 功能

- **像素编辑**：画笔、填充、选区移动、橡皮、取色；16×16 画布、缩放、网格。
- **脚本录制**：开启「录制」后，画笔笔画、填充、选区移动自动记成**带参数的步骤**（颜色 / 区域 / 位移 / 坐标点），也可手动添加并在列表中直接编辑参数、排序、删除。
- **帧范围绑定与重放**：每个脚本绑定帧范围（起–止），支持**正向 / 反向 / 镜像**（往返）三种重放序列。
- **逐帧预览**：批量应用前以缩略图序列预览每一帧的结果，预览不改动画布。
- **脚本嵌套**：步骤可引用其他脚本实现复用；添加引用与应用执行时都会检测并**阻止循环依赖**；**越界步骤**（坐标 / 区域超出画布）会被阻止。
- **事务化批量应用**：一次批量应用只占 **1 次撤销**；任一步骤失败，整批自动回滚，不留半残状态。
- **持久一致**：保存后刷新页面结果一致；导出的 JSON 重新导入后逐字节一致。
- **键盘与窄屏**：`B/F/M/E/I` 切工具，方向键移动光标，`Enter` 作画，`[` `]` 切帧，`R` 录制，`P` 预览，`Ctrl+Z/Y` 撤销重做，`Ctrl+S` 保存，`Esc` 取消选区；≤680px 视口自动折叠为单列布局。

## 测试

真实浏览器（Chromium）端到端测试，覆盖：空脚本、单步、反向、镜像、嵌套循环、跨帧、失败回滚、保存刷新、导出导入、键盘、窄屏、填充与移动录制。

```bash
npm install
npx playwright install chromium
npx playwright test
```

## 结构

```
index.html      页面结构
css/style.css   样式（含窄屏响应式）
js/engine.js    脚本引擎：步骤应用 / 帧序列 / 校验 / 循环检测（纯逻辑）
js/app.js       状态、撤销、录制、预览、批量应用、持久化、导入导出、键盘
tests/          Playwright 端到端测试
```
